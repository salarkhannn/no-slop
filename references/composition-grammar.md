# Composition grammar

Use for new pages and material redesigns. Composition means the relationship between
navigation, work surface, content, controls, and state—not the order of generic sections.

## 1. Choose topology from the work

| Topology | Best for |
| --- | --- |
| Canvas | spatial creation, diagrams, open-ended manipulation |
| Database | shared properties, sorting, filtering, comparison, bulk work |
| Board | records moving through categorical states |
| Timeline | sequence, duration, causality, scheduling |
| Document | reading, writing, annotations, nested blocks |
| Gallery | visually led objects that still need metadata and actions |
| Masonry collection | heterogeneous saved media or knowledge objects |
| Split pane | scan a collection while inspecting or editing one object |
| Record workspace | one object with properties, relationships, activity, and actions |
| Ledger | dense chronological or financial comparison |
| Hybrid | one dominant topology plus one supporting topology |

Do not choose a table because the data is an array or cards because items repeat.

## 2. Structural candidate contract

For the same evidence, create three candidates. Record:

```text
Topology:
First scan / focal anchor:
Navigation relationship:
Primary work surface:
Density and grouping:
Symmetry model:
Surface and depth:
Compound interactions:
Media strategy:
Narrow-screen transformation:
```

Candidates must differ in at least four fields. Swapping section order, changing column
count, or moving the same cards around does not qualify.

Reject two candidates with a task consequence:

- comparison becomes slower;
- object context is lost;
- the principal action becomes remote;
- dense content is trapped;
- narrative proof arrives too late;
- narrow-screen transformation destroys priority.

## 3. Focal anchors

Valid focal anchors include:

- the active record or canvas;
- exception queue;
- filter/query builder;
- primary object preview;
- decision comparison;
- product demonstration;
- meaningful media;
- current step or unresolved state.

A large headline is not automatically the focal anchor. It must earn the space or yield it
to the work.

## 4. Route differentiation

Sibling routes share shell primitives, not necessarily page skeletons. For each route name:

- primary object;
- repeated task;
- topology;
- dominant interaction;
- information density;
- state model.

If three routes all resolve to title + description + action + filters + table/cards, review
whether the task models were ignored.

## 5. Responsive topology

Transform relationships rather than shrinking:

- split pane → list then detail sheet or staged navigation;
- board → grouped vertical list or horizontal swimlane scroll with clear scope;
- database → prioritized columns plus inspector;
- masonry → fewer columns while preserving item prominence;
- record workspace → collapsible property rail and persistent object identity;
- canvas → viewport controls and explicit overflow, not forced stacking.

## 6. Monotony review

Reject a composition when:

- every region shares one surface treatment and density;
- visual interest depends only on color inversion;
- large empty areas do not improve focus, reading, manipulation, or hierarchy;
- the only structural variation is alternating left/right text;
- important interaction is represented as static explanatory copy;
- the composition could be transferred unchanged to an unrelated product.
